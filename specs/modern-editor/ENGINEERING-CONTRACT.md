# Fresh editor implementation contract

This branch starts from upstream main e668010778568641babef2cc40be4703ae6916d6. The Classic-derived prototype in PR #1 is a historical reference, not this product's implementation. New domain logic, interface, renderer, persistence and media workers must be authored here. No imports or copied implementation from apps/studio, OpenCutClassic or opencut-wasm. Current maintained third-party infrastructure remains appropriate for codecs, UI primitives and the desktop shell.

Shared domain: packages/editor-core/src/types.ts. Integer ticks use 240000 ticks/second. Common fractional frame rates have integral frame ticks; decoded audio conforms to 48 kHz. JSON must be validated at native and project-load boundaries. Core revision counts commands; storage version counts acknowledged writes. Saves use compare-and-swap storage versions.

Core public API required by UI/native: createProject({id?,name?,width?,height?,frameRate?}), createClip({id?,asset,start?,duration?}), createTextClip({id?,text?,start?,duration?}), validateProject(unknown), projectDuration(project), secondsToTicks(seconds), ticksToSeconds(ticks), snapToFrame(ticks,frameRate), applyCommand(project,command), evaluateClip(clip,timeRelativeToClip), buildRenderPlan(project), parseSrt(text), toSrt(captions), and EditorStore(project) with getSnapshot(), dispatch(command), undo(), redo(), canUndo(), canRedo(), replaceProject(project), subscribe(callback). Keyframes are clip-local, sourceIn is source time, timeline duration is independent of source span and speed must respect media bounds. A batch is one Undo step; history never crosses projects.

Desktop host API: EditorHost in types.ts. Renderer receives opaque media URLs, never arbitrary filesystem powers. Main owns imported-file registrations, native dialogs, project SQLite, jobs and output paths. FFmpeg/ffprobe run as child processes with argument arrays, never shell strings. No cloud/model downloads, external requests or credential access by default. Job cancellation must stop the child and produce one terminal state.

Preview and export consume the same RenderPlan. Unsupported export properties must produce a clear failure; never silently render a different result. A feature is complete only after a meaningful implementation and test. Provider/plugin interfaces alone are not completed AI features. Feature statuses must remain explicit.

Native local transcription uses transcribeAsset(assetId) with a transcription Job whose result is Caption[]. getEnvironment reports localTranscription and transcriptionModel when a configured GGML model and FFmpeg whisper filter are usable. No model is downloaded by the app automatically. Returned caption timestamps are relative to the whole source asset; the UI maps them through sourceIn, speed and start when applying to a selected clip. Initial default is local-first processing; cloud providers remain unavailable until separately implemented/configured. Neutral color multipliers are brightness=contrast=saturation=1; 0..2 bounds. Transform x/y offset the centered contain-fit media in canvas pixels. Render segments are bottom-to-top; later segments draw over earlier ones.

Root owns setup, shared contract, integration, packaging and final QA. Core worker owns packages/editor-core (except this initial types contract); frontend worker owns apps/editor/src; native worker owns apps/editor/electron and native tests. Workers must not edit package metadata or each other's scope. No worker commits, app launches, server listeners, installs or external writes without coordination.
