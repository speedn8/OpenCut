# OpenCut Studio source attribution

This local editor includes source and public assets from **OpenCut Classic**, MIT licensed:
https://github.com/OpenCut-app/opencut-classic/tree/cf5e79e919144200294fb9fed22a222592a0aeea

The upstream copyright and license are reproduced in `LICENSE-CLASSIC`. `CLASSIC-SOURCE.json` records the exact original source identities. Changes adapt the browser editor to a local desktop shell, improve persistence and remove hosted integrations. The existing GPUI rewrite remains a separate application.

The app uses the published `opencut-wasm` Rust library and other open-source dependencies under their respective licenses. The packaged application includes Electron's Chromium notices.

CapCut's reverse-engineering evidence guides behavioral comparisons. No extracted CapCut source, native binary, model, proprietary asset or credential is included in this implementation.
